# Royal Islamic Wedding Invitation (Nikah & Valima)

A streamlined, ultra-luxurious, highly animated, 60fps responsive Islamic wedding digital invitation application for **Zayd & Fatima**.

## ✨ Features & Highlights

1. **Royal Envelope & Wax Seal Gatefold**:
   - Interactive opening ceremony with Arabic "نِكَاح" wax seal unsealing animation.
   - Dual-door 3D fold-out and celebratory gold/emerald confetti burst.
   - Re-openable anytime via the top navigation bar.

2. **Ultra-Smooth 60fps Islamic Aesthetics (Lag-Free & Zero Hang)**:
   - **Canvas Gold Stardust Particle System**: Hardware-accelerated floating stardust that pauses automatically when the tab is hidden (`document.hidden`).
   - **Swaying Moroccan Fanous Lanterns**: Pure CSS3 GPU-accelerated pendular swing with realistic flickering candle flames (`will-change: transform`).
   - **Arabic Calligraphy & Typography**: Sacred Bismillah, Surah Ar-Rum [30:21], and Hadith blessings in Amiri script with metallic gold foil shimmer effects.

3. **Sacred Islamic Typography & Calligraphy**:
   - **Basmala Calligraphy**: *بِسْمِ اللَّهِ الرَّحْمَٰنِ الرَّحِيمِ* in shimmering gold script.
   - **Surah Ar-Rum [30:21]**: Sacred verse in authentic Arabic calligraphy with English translation.
   - **Couple Names**: Zayd Al-Mansur & Fatima Al-Zahra.
   - **Live Countdown Timer**: Real-time days, hours, minutes, and seconds countdown to the Nikah ceremony.

4. **Program of Auspicious Events (Nikah & Valima)**:
   - **The Sacred Nikah Ceremony**: Date, time, venue, address, and description of the sacred covenant under the Sunnah of Prophet Muhammad (PBUH).
   - **Dawat-e-Valima Reception**: The celebratory Sunnah feast of thanksgiving, banquet details, and venue.
   - **1-Click Google Calendar** integration.
   - **1-Click iCal (.ics)** download for Apple Calendar and Outlook.
   - **Google Maps directions** & instant venue address copy.

5. **Sacred Hadith & Family Regards**:
   - Prophetic blessing: *بَارَكَ اللَّهُ لَكُمَا وَبَارَكَ عَلَيْكُمَا وَجَمَعَ بَيْنَكُمَا فِي خَيْرٍ* (Sunan Abi Dawud).
   - Contact hotline and family blessing notes.

## 🚀 Running the Project

```bash
# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
